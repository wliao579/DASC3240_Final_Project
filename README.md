# DASC3240_Final_Project

## Purpose
This Repo was made for the final project of DASC3240, in which we have to use a dataset, conduct analysis and present our findings on a Shiny app. Each group member did data exploration on a certain open-source dataset, and we got together to discuss which dataset we think will make the best visualization. The dataset "basketball.csv" was chosen. The dataset contains WNBA players' performance statistics from the 2019 season.
